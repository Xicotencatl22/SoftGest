# Taller Autoservicio San Jorge

## Descripción

El proyecto consiste en el desarrollo de un sistema web para la administración y gestión de los procesos de un taller automotriz. El sistema busca centralizar la información del taller y facilitar el control de clientes, vehículos, servicios, refacciones y cotizaciones.

## Propósito

El propósito principal del proyecto es desarrollar una herramienta que permita mejorar la organización y administración de las actividades del taller, reduciendo errores, tiempos de trabajo y pérdida de información.

El sistema permitirá gestionar de manera organizada la información relacionada con los vehículos, servicios y refacciones, además de facilitar la elaboración y seguimiento de cotizaciones.

## Justificación

El proyecto surge de la necesidad de mejorar la administración y gestión de los procesos del Taller Autoservicio San Jorge. Actualmente, problemas como la falta de organización del inventario, información desactualizada, pérdida de datos importantes y retrasos en la elaboración de cotizaciones pueden afectar la eficiencia del taller y la atención a los clientes.

Por esta razón, se propone desarrollar un sistema de software que permita centralizar y automatizar la información relacionada con clientes, vehículos, servicios, refacciones y cotizaciones.

El propósito principal del sistema es facilitar la administración de las operaciones del taller, reducir errores y tiempos de trabajo, mantener la información organizada y permitir un mejor control de los recursos disponibles.

Además, el proyecto permitirá aplicar buenas prácticas de desarrollo de software, utilizando control de versiones, pruebas y procesos de integración y despliegue continuo (CI/CD), con el objetivo de obtener un sistema funcional, organizado y fácil de mantener.

## Funcionalidades

- Gestión de clientes.
- Gestión de vehículos.
- Gestión de marcas, modelos, años y motores.
- Gestión de servicios.
- Gestión de refacciones.
- Elaboración de cotizaciones.
- Control de inventario.
- Registro y seguimiento de servicios.
- Generación de reportes.
- Control de ventas y pagos.

## Control de Versiones

El proyecto utiliza Git y GitHub para llevar el control de versiones del código fuente, permitiendo trabajar mediante ramas y mantener un historial de cambios.

## CI/CD

Se busca implementar un flujo de Integración Continua y Despliegue Continuo (CI/CD), permitiendo automatizar procesos como:

- Verificación del código.
- Ejecución de pruebas.
- Integración de cambios.
- Construcción del proyecto.
- Despliegue de la aplicación.
